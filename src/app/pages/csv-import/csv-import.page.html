Import weight logs

Import weight logs from a CSV file. Each row becomes one weight log.

Supported format

Header row required

The first row must contain column names. Columns can be in any order.

  • date (required): YYYY-MM-DD, optionally followed by a time.
  • weight (required): a positive number.
  • unit (optional): kg, lbs or st. Blank or missing uses your current unit.
  • notes (optional): free text. Use quotes if it contains commas.

Example

date,weight,unit,notes
2024-05-01,82.4,kg,Morning
2024-05-02,181.2,lbs,
2024-05-03,82.1,,

Good to know

Only one log is kept per day. If a date already has a log, the existing one is kept and the imported duplicate is skipped. Invalid rows are ignored and counted in the summary.
