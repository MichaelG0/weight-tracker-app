Import weight logs

Import weight logs from a CSV file. Exports from most weight tracker apps will work, no changes needed.

Using your own file?

Include a header row with at least a date and a weight column, in any order.

  • date: most common formats work, e.g. 2024-05-01, 2024/05/01, or 01/05/2024. A time is ignored.
  • weight: a number, e.g. 82.4 or 82,4.
  • unit (optional): kg, lbs or st. Blank uses your current unit.
  • notes (optional): free text.

Example

date,weight,unit,notes
2024-05-01,82.4,kg,Morning
2024-05-02,181.2,lbs,
2024-05-03,82.1,,

Good to know

One log is kept per day: existing logs are never overwritten, and duplicates and invalid rows are skipped. A summary is shown after importing.
